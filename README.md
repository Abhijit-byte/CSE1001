# CSE1001 - ICP Programming Assignments

A comprehensive collection of Java programming assignments for CSE1001 Introduction to Computer Programming (ICP) course.

## 🌐 Live Website

View the professional portfolio website showcasing all assignments: [CSE1001 Portfolio](https://abhijit-byte.github.io/CSE1001/)

## 📚 Assignment Collections

This repository contains four complete assignment sets:

### ICP Assignment 1 (10 Programs)
- **Focus**: Basic Java syntax, string handling, console I/O
- **Topics**: Fundamental programming concepts
- **Files**: `ICP Assisgnment 1/Assignment/`

### ICP Assignment 2 (7 Programs + Home Work)
- **Focus**: Mathematical operations, user input, command-line arguments
- **Topics**: Temperature conversion, calculations, CLI handling
- **Files**: `ICP Assignment 2/Assignment/`, `ICP Assignment 2/Home Assignment/`, `ICP Assignment 2/Command Line/`

### ICP Assignment 3 (10 Programs + Home Work)
- **Focus**: Control structures, loops, advanced problem-solving
- **Topics**: Conditional statements, iterations, complex logic
- **Files**: `ICP Assignment 3/Assignment/`, `ICP Assignment 3/Home Assignment/`

### ICP Assignment 4 (10 Programs + Home Work)
- **Focus**: Advanced Java features and complex programming challenges
- **Topics**: Best practices, optimization, comprehensive solutions
- **Files**: `ICP Assignment 4/Assignment/`, `ICP Assignment 4/Home Assignment/`
